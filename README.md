## Deskripsi Proyek
 
Halaman portofolio satu halaman *landing page* untuk seorang *Software Engineer* (pengembang perangkat lunak). Halaman ini dibangun dengan **HTML5 semantik dan CSS3 murni**, tanpa framework. Tampilan dirancang dengan pendekatan **mobile-first** dan responsif untuk lebar layar 320px hingga 1920px.
 
Gaya visualnya sederhana dan minimalis dengan palet warna **biru, hijau, dan krem**.
 
## Fitur dan Bagian Halaman
 
| Bagian | Isi |
|---|---|
| **Home** | Judul "PORTOFOLIO", foto profil, peran, lokasi, dan tombol *Explore* (ke bagian projects)|
| **About Me** | Biografi singkat dalam kartu dengan dekorasi gambar |
| **Skills** | Tumpukan teknologi (*tech stack*): Front End (HTML5, CSS3, JavaScript) dan Back End (Node.js, Python, Laravel) |
| **Certifications** | Sertifikasi utama BNSP Junior Web Developer, ditambah sidebar Wireshark Network Analyst, CompTIA Network+, dan SolarWinds Certified Professional |
| **Projects** | Galeri kartu proyek unggulan (PT. Jual Rumah, Aplikasi Toko Lalu Lalang, Sistem POS IndoAbadi) |
| **Contact** | Telepon, email, dan tautan media sosial (Instagram, LinkedIn, TikTok) |
 
Fitur tambahan: navigasi anchor dengan *smooth scroll*, *skip link* untuk pengguna papan ketik, dan efek *hover/focus* yang jelas pada tautan dan tombol.
 
## Teknologi
 
- HTML5 (semantik)
- CSS3 murni: Custom Properties, Flexbox, CSS Grid, Media Queries
- Font dari Google Fonts: *Unbounded* (judul) dan *Plus Jakarta Sans* (teks)
